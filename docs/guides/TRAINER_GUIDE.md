# Trainer guide (Mahgol)

Plain-English guide for running the academy on the platform. Screenshots: store under Project `media/` with filenames referenced here when added.

## Getting started

- Sign in with your CDS Google account.
- Open **Trainer** in the sidebar: **Users**, **Content**, **Marking**, **Placements**.

## People and cohorts

- **Users:** assign department, cohort, stream, and active flag. New starters stay on **setup pending** until they have a department.
- **Cohorts:** set Week 0 start (Monday) and **breaks** so programme weeks match the calendar.

## Content

- **Lessons / help / updates:** write Markdown in the editor; publish when ready. Images upload to private storage and appear via signed URLs.
- **Assessments and assignments:** import JSON where provided; publish separately from draft. Sample content is for **development only**.

## Marking

- **Week 0:** Placements tab — calculate suggestion, confirm stream, allow retake when needed.
- **Assignments:** Marking hub — primary marks, request resubmission, release feedback. **Moderation** when double-marks disagree.
- **Champions:** only see submissions assigned for double-mark.

## Test-outs and plans

- Confirm placement builds the learner plan. **Overrides** need a reason and stay when the plan is regenerated.
- Test-out quizzes and assignments update plan gates when passed (see programme architecture / DL-027).

## Progress

- **People / Departments / Modules / Weekly** tabs; optional **Include test accounts** on dev only.
- Managers see counts, not mark columns.

## When someone is locked out

- **Setup pending:** assign a department.
- **Paused:** admin or trainer reactivates in Users.
- **Wrong Google account:** they must use `@caspiands.com`.
